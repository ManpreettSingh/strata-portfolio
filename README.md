# Strata Portfolio (Frontend)

This is the frontend of the Strata Portfolio platform, built with React, Vite, and TanStack Router.

## Deployment on Vercel

1. Push this code to your GitHub repository.
2. In Vercel, click **Add New** → **Project** and select this repository.
3. Vercel will automatically detect Vite. Leave the build command as `npm run build`.
4. Set the `VITE_API_BASE_URL` environment variable to point to your backend URL (e.g., `https://foliobackend-production.up.railway.app`).
5. Click **Deploy**.
